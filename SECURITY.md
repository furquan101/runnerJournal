# Security

Runner Journal runs entirely in your browser. Journal entries, synced Strava and Oura data, and your API keys are stored locally and sent only to OpenRouter, Strava and Oura.

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private vulnerability reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply as soon as possible.

## Good practice for users

- Use a personal OpenRouter key with a spending limit.
- Don't run the app on a shared or public computer, since keys are stored in the browser.
- Disconnect Strava and Oura from **Connections** if you stop using the app.
